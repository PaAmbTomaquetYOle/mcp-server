# mcp-server
MCP server to give functionalities to the agent

## Local development

Run the server:

```powershell
uv run mcp-server
```

Open the MCP Inspector:

```powershell
uv run mcp-inspector
```

Open the Inspector already pointed to the local server:

```powershell
uv run mcp-inspector-local
```

Then connect it to:

```text
http://localhost:8000/mcp
```
